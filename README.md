# Developer's Canvas

Full-Stack Developer Portfolio Website



Build a modern, premium, fully responsive personal portfolio website for a Full Stack Developer. The design should be clean, elegant, and professional, with smooth animations and excellent user experience.



Design Style

Modern and minimal.

Premium UI inspired by top developer portfolios.

Smooth scrolling.

Subtle animations using Framer Motion or similar.

Rounded cards with soft shadows.

Glassmorphism effects where appropriate.

Gradient highlights.

Fast loading.

Mobile-first and fully responsive.

Technical Requirements

Build using html, css and js.

Ensure accessibility best practices.

Optimize for performance and SEO.

Include dark mode by default with an optional light mode toggle.

Organize the code into reusable components.

Make every page fully responsive across desktop, tablet, and mobile devices.

Add placeholder content for images, projects, work experience, biography, and contact details so they can easily be replaced later.
